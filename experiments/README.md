# Experiments

This directory contains performance benchmarks for DJGen. Each experiment shares the same structure:

- `config/` - TOML configuration files, one per trial
- `results.csv` - Collected results where each row corresponds to a configuration
- `results.png` - Visualization of the results
- `plot.py` - Script to generate the visualization from `results.csv`

## Experiments

### data-gen

Benchmarks the raw data generation performance of DJGen. Each trial increases the number of tuples generated by a power of ten, ranging from 100K to 10B.

### pipeline

Benchmarks the performance of the entire pipeline (data generation, plan generation, and analysis) at increasing scales. Each trial N generates N relations with 10M tuples and N attributes (e.g., size 3 corresponds to 3 relations with 3 attributes each).

## Running

Run a trial by passing its config file to DJGen from the project root. Use the `-t` flag to enable timing output:

```bash
python -m src.main -t run experiments/<experiment>/config/<config>.toml
```

After collecting results into `results.csv`, generate the plot from within the experiment directory:

```bash
cd experiments/<experiment>
uv run plot.py
```
